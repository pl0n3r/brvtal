## Método

`CUBIERTO` requiere código + prueba existente + PR **MERGED** comprobado y solo representa la porción probada. `DESCARTADO` excluye del conteo atómico frases introductorias o exclusiones de alcance, sin cancelar el deber general. `NO_VERIFICABLE` expresa la prueba **integral** ausente (no significa ausencia de implementación). `SIN_COBERTURA` exige brecha positivamente verificada y hoja específica auténtica. En este corte no se inventan hojas ni resultados.

Fuente histórica de implementación: [PR #572](https://github.com/pl0n3r/brvtal/pull/572) integra Factory v1 en BRVTAL, y [PR #574](https://github.com/pl0n3r/brvtal/pull/574) integra el gestor de cambios del editor.
