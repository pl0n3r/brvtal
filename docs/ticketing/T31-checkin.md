# T31: puerta HTTP y UI después de emisión (#2018)

El escenario obligatorio de checkout reutiliza el QR **exacto** recuperado por la cuenta del comprador después de pago firmado y emisión real. No se siembra entrada, credencial, sesión ni auditoría. Tras terminar los asserts existentes, solo se avanza el reloj del evento sintético a su ventana de admisión en la BD descartable. Se crean dos staff `door` y un rol sin permiso, autenticados por la API real. Se conserva el escenario promo cuando esté presente.

- AC-01: dos Chromium contexts independientes a 390 px envían POST legítimos con CSRF y request IDs distintos. El proxy TLS espera ambas solicitudes antes de reenviarlas a PHP con workers separados; no fabrica respuestas. Se exige 200/409, allow/deny, estado used y un único audit accepted vinculado a la misma entrada, evento, versión y operador. El rechazo `already_used` queda auditado.
- AC-02: HTTP 401 sin sesión, 419 sin CSRF válido, 403 rol sin permiso, 409 wrong_event/malformed_qr; cero ingresos antes de la carrera. Chromium offline en la frontera de transporte exige estado deny y ningún cambio de auditoría; el texto de rechazo no revela datos de comprador. Se usa el fragmento PHP real y módulo JS/CSS real, sin interceptar APIs. El fixture solo confía en su CA efímera, sin ignorar errores TLS.
- AC-03: `real-stack` exige recibo `T31_CHECKIN_STACK_PASS` en TAP del escenario checkout, además del recibo checkout ya existente; un skip o falta de recibo falla cerrado. El runner conserva `--network none`, almacenamiento descartable y guardas de MariaDB. Solo se descargan navegador y librería durante el build. No se imprime QR, sesión, correo o raw TAP.

Ejecutar `bash tests/e2e/run-ticketing-real-stack.sh` (CI; local con `BRVTAL_T31_FIXTURE_LOCAL=1` y Docker). La evidencia canónica es el recibo y `real-stack` / `validate` terminales del SHA exacto del PR. Revertir el squash retira solo tests, wiring y este documento. No certifica producción, reemisión, reembolso, conciliación, T31 completo ni habilitación de ventas.
